# 🎓📚 Collection Manipulator

> 🚀 **A Python Mini Project for Student Data Management Using Python Collections**

---

# 📖 About the Project

The **Collection Manipulator** is a beginner-friendly Python project that demonstrates the practical use of Python collection data types. It is designed as a **Student Data Organizer**, where users can easily add, view, update, delete, and manage student records.

This project helps learners understand how different Python collections work together to build a real-world application.
